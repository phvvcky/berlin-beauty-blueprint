# Berlin Beauty Blueprint

Build a complete, premium, modern website for Angel Nails Berlin, a Vietnamese-owned nail and beauty studio.

This is not just a one-off website. This is the first implementation of a reusable Beauty / Nail Studio website template that I want to use later for other Vietnamese-owned nail studios and beauty businesses in Berlin.

The website should therefore look highly customized and premium for Angel Nails, while the underlying components, design system and content structure should be reusable.

IMPORTANT:

If information conflicts between sources, prefer the most recent/current information and do not silently invent an answer.

Do not copy the existing websites' design, layout or visual identity.
The goal is a significant redesign and modernization.

2. BUSINESS CONTEXT

Angel Nails is a nail and beauty business serving customers in Berlin.

The business currently has two locations:

Berlin / Prenzlauer Berg

Hennigsdorf

Make sure these two locations are clearly distinguished throughout the website.

The main conversion goal is:

Get visitors to book an appointment.

Secondary goals:

communicate quality

showcase nail work visually

make services and prices easy to understand

build trust

make locations easy to find

make contact easy

connect visitors with Instagram

Most visitors will likely come from Instagram and Google and will use a mobile phone.

Therefore the website must be strongly mobile-first.

3. DESIGN DIRECTION

Create a premium Berlin beauty-brand aesthetic.

The website should feel:

modern

elegant

minimal

sophisticated

feminine but not overly cute

editorial

high-end

visually driven

confident

clean

Think more:

premium Berlin beauty studio / fashion editorial / modern lifestyle brand

and less:

generic nail salon template / cheap beauty website / AI-generated landing page

Avoid:

excessive pink

cheesy beauty aesthetics

excessive gradients

excessive rounded cards

generic stock photography

huge amounts of text

unnecessary animations

clutter

generic AI-looking sections

Use strong typography, generous whitespace, large imagery and clear visual hierarchy.

4. HOMEPAGE

Create a strong homepage with the following structure:

HERO

Large premium hero section.

Communicate immediately:

Angel Nails

Nail & Beauty Studio

Berlin

Primary CTA:

Termin buchen

Secondary CTA:

Leistungen ansehen

Use a large, visually striking image or image placeholder.

The hero should immediately communicate quality and make the visitor want to continue scrolling.

TRUST / INTRO

Short introduction to Angel Nails.

Keep it concise.

Focus on:

experience

quality

beauty

personal service

trust

Do not create long generic marketing copy.

SERVICES

Show the most important services.

Examples may include categories such as:

Maniküre

Gel / Nagelmodellage

Nail Art

Pediküre

Wimpern

Augenbrauen

weitere Beauty-Leistungen

Use the actual services found in the provided sources where possible.

Prices should be displayed clearly where available.

Structure the data so services and prices can easily be changed later.

FEATURED WORK / GALLERY

This should be one of the strongest sections on the website.

Create a premium visual gallery showcasing nail and beauty work.

The gallery should feel like an Instagram-quality portfolio.

Use image placeholders for now if necessary.

Make it easy to replace placeholder images with real Angel Nails images later.

REVIEWS / SOCIAL PROOF

Create a visually elegant customer review section.

Use verified review information from the provided sources where appropriate.

Do NOT fabricate reviews.

Include review source attribution where necessary.

LOCATIONS

Create a clear section for the two locations.

Location 1:
Berlin / Prenzlauer Berg

Location 2:
Hennigsdorf

Each location should have:

address placeholder or verified address

opening hours

map / Google Maps CTA

booking CTA

relevant contact information

Do not merge the two locations into one.

INSTAGRAM

Create a visually strong Instagram section.

Show recent-work style imagery / placeholders.

CTA:

Instagram ansehen

Link to:

https://www.instagram.com/angel_nails_nagelstudio/?hl=de

Do not pretend to have a live Instagram feed unless a real integration is implemented.

FINAL CTA

End the homepage with a strong conversion section.

Example direction:

Bereit für deinen nächsten Look?

CTA:

Termin buchen

5. SERVICES PAGE

Create a dedicated services page.

Organize services into logical categories.

Use the actual services and prices from the available sources.

The structure must make it easy to edit:

service name

description

price

duration if available

category

Do not hardcode these values throughout the UI.

Create a reusable data structure for services.

6. GALLERY PAGE

Create a dedicated gallery / portfolio page.

The focus should be visual.

Use a sophisticated masonry or editorial-style grid where appropriate.

The layout should work beautifully on mobile.

7. ABOUT PAGE

Create an About page for Angel Nails.

Use factual information from the provided sources.

Focus on:

who Angel Nails is

experience

quality

team

personal service

locations

Keep it human and concise.

Do not invent a fictional company story.

8. CONTACT / LOCATIONS PAGE

Create a dedicated contact page.

Include both locations.

Include:

address

opening hours

phone

Instagram

booking CTA

Google Maps CTA

Use verified information where available.

9. BOOKING

Booking is the most important conversion action.

Use a clear, repeated primary CTA:

Termin buchen

Angel Nails uses external booking flows.

Do not create a fake custom booking system.

Use the real booking links from the provided sources where they can be verified.

If a booking URL cannot be safely determined, create a clearly marked placeholder that can easily be replaced.

Make booking CTAs highly visible on mobile.

Consider a sticky mobile CTA such as:

Termin buchen

10. LANGUAGE

Primary language:

German

Structure the website so that English and Vietnamese can be added later.

Do not build a complicated translation system unless necessary.

Keep all customer-facing content structured so it can later be translated easily.

11. SEO

Implement strong local SEO foundations.

Include:

semantic HTML

proper H1 / H2 / H3 hierarchy

unique page titles

meta descriptions

descriptive URLs

image alt text

local business structured data where appropriate

beauty salon / nail salon relevant structured data where appropriate

location-specific content

fast loading

mobile optimization

Do not keyword-stuff.

12. DESIGN SYSTEM

Create a reusable design system.

Use centralized variables/tokens for:

colors

typography

spacing

border radius

shadows

buttons

responsive breakpoints

Make the visual system easy to modify later.

The system should be reusable for future beauty/nail clients.

13. REUSABLE COMPONENT ARCHITECTURE

Create reusable components for:

Header

Navigation

Hero

CTA

Services

Service category

Gallery

Reviews

Location

Opening hours

Instagram section

Footer

Booking CTA

Keep business content separate from presentation wherever practical.

For example, business information such as:

business name

logo

colors

services

prices

locations

opening hours

phone

Instagram URL

booking URLs

should be easy to modify without rebuilding the components.

This is important because this website will later become a reusable template for other businesses.

14. RESPONSIVE DESIGN

Mobile-first.

Test carefully for:

small mobile screens

normal mobile screens

tablet

desktop

large desktop

The mobile experience is the highest priority.

Make buttons easy to tap.

Avoid tiny text.

Avoid horizontal scrolling.

Make navigation simple.

15. PERFORMANCE

Prioritize:

fast loading

optimized images

lazy loading where appropriate

minimal unnecessary dependencies

clean component structure

good Core Web Vitals

Do not add unnecessary libraries just for visual effects.

16. ACCESSIBILITY

Use:

semantic HTML

accessible buttons

meaningful alt text

keyboard navigation

sufficient contrast

visible focus states

accessible navigation

17. IMAGES

For the prototype, use high-quality image placeholders or suitable temporary imagery.

Do not assume that images from the existing websites can automatically be reused commercially.

The final system should make it extremely easy to upload and replace images with real Angel Nails photos.

Prioritize large visual images because the beauty work itself is a major selling point.

18. IMPORTANT PRODUCT REQUIREMENT

This website is also the foundation for a future business.

I want to eventually use this system to build websites for many other Vietnamese-owned nail studios and beauty businesses in Berlin.

Therefore:

Do not build everything as one giant hardcoded page.

Create a clean reusable architecture.

Think of this as:

Beauty Website Template v1

with Angel Nails as the first real implementation.

The visual result should NOT look like a generic template.

It should look like a custom premium website specifically designed for Angel Nails.

19. FINAL QUALITY BAR

Before considering the implementation complete, ask yourself:

Does this look like a €50 template?

If yes, improve it.

It should instead feel like a professional premium Berlin beauty brand website.

Prioritize:

visual quality

mobile experience

conversion / booking

strong imagery

clear services

trust

reusable architecture

SEO

performance

Do not over-engineer the project.

Build the first polished version and make the result visually impressive.
